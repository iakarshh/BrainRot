# BRAINROT.exe 💀

A beginner-friendly, funny Hinglish meme website made with plain HTML, CSS and JavaScript.

## Run it on your computer
1. Download `index.html`.
2. Double-click it to open in Chrome, Edge, or Firefox.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **new public repository** named `brainrot-exe`.
2. On the repository page, choose **Add file → Upload files**.
3. Upload `index.html` and this `README.md`.
4. Click **Commit changes**.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main`, folder `/(root)`, then click **Save**.
8. Wait a minute or two. Your site should appear at:
   `https://YOUR-USERNAME.github.io/brainrot-exe/`

Replace `YOUR-USERNAME` with your GitHub username.

## Customize
- Change jokes in the `jokes` array near the bottom of `index.html`.
- Change friendly roasts in the `roasts` array.
- Colors are defined at the top of the CSS inside `:root`.

## Notes
- No frameworks, packages, accounts, or tracking.
- Scanner is a fictional joke, not a real medical or psychological test.
- Sharing uses the browser's native share menu where supported, otherwise it copies text/link.
